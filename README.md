# Prop Firm Tracker

Independent comparison of futures prop firms for algo traders.

## Stack
- Astro (static site)
- Cloudflare Pages (hosting, free)
- GitHub (source + auto-deploy)

## Local dev
```
npm install
npm run dev
```

## Update firm data
Edit `src/data/firms.json` — rebuild and push to deploy.

## Deploy
Push to GitHub main branch → Cloudflare Pages auto-deploys.
